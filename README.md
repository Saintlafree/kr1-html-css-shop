# ТехноЛавка — учебный интернет-магазин (КР №1)

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Дисциплина: «Фронтенд и бэкенд разработка», 3 семестр, 2026/2027 уч. год.

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина гаджетов и аксессуаров «ТехноЛавка». Сайт выполнен без CSS-фреймворков. JavaScript используется минимально: для открытия модального окна и базовой проверки форм.

## Самостоятельные доработки

Что добавлено сверх пошаговых методических указаний:

1. **Собственная визуальная концепция.** Бренд «ТехноЛавка» с логотипом, своя палитра (индиго + оранжевый акцент), тени, градиент в hero-блоке, тёмный подвал. Все значения заданы переменными в `:root`.
2. **Расширенный каталог.** 6 товаров в трёх категориях (Аудио, Гаджеты, Аксессуары), ссылки-«чипсы» на категории, счётчик товаров, фильтры по категории, метке и цене, кнопка «Сбросить».
3. **Улучшенные карточки.** Собственные SVG-иллюстрации, категория, бейджи «Хит», «Новинка», «Скидка» (модификаторы `product-card__badge--*`), старая цена для товаров со скидкой, две кнопки («Подробнее» и «Заказать»), эффект подъёма при наведении.
4. **Подробная страница товара.** Галерея с бейджем, рейтинг, список особенностей, таблица характеристик с «зеброй», комплектация, блок «С этим товаром смотрят».
5. **Новые блоки главной.** Преимущества с иконками на Grid, отзывы покупателей, FAQ на `<details>`/`<summary>` (работает без JavaScript), промо-блок «Акция недели».
6. **Доработка форм и сценария заявки.** Полноценная форма на `order.html` с группами `fieldset` (контакты, товар, доставка), радиокнопки способа доставки, количество, очистка формы. Форма обратной связи на `contacts.html`. В модальном окне показывается выбранный товар, окно закрывается кликом по фону. Подсветка ошибки снимается, как только поле исправлено. Обязательные поля отмечены звёздочкой. Один обработчик в `main.js` обслуживает все формы с атрибутом `data-validate`.
7. **Позиционирование.** Липкая шапка (`sticky`) с `scroll-padding-top`, чтобы якоря не прятались под ней. Липкие фильтры каталога и блок доставки. Фиксированная кнопка «Наверх» (`fixed`, `z-index`).
8. **Доступность.** Ссылка «Перейти к основному содержимому», `aria-current="page"` у активного пункта меню и в хлебных крошках, хорошо заметный фокус (`:focus-visible`), `aria-describedby` для подсказки к телефону, `role="status"` у сообщений об успехе, скрытый текст для экранных дикторов (`.visually-hidden`), учёт `prefers-reduced-motion`, `alt` у всех изображений.
9. **Дополнительно.** Страница `404.html` для GitHub Pages, favicon, Open Graph-разметка с превью `images/preview.jpg`, `sitemap.xml`.

## БЭМ-структура проекта

Основные блоки: `site-header`, `site-nav`, `breadcrumbs`, `page`, `hero`, `section`, `advantages-list`, `products-grid`, `product-card`, `reviews`/`review`, `faq`, `aside-info`, `category-links`, `catalog-layout`, `catalog-filters`, `catalog-products`, `catalog-category`, `product`, `product-table`, `order-layout`, `order-aside`, `order-dialog`, `order-form`, `contacts-layout`, `contacts-card`, `contacts-list`, `success-message`, `button`, `to-top`, `not-found`, `site-footer`.

Примеры модификаторов: `site-nav__link--active`, `product-card--featured`, `product-card--discount`, `product-card__badge--new`, `button--primary`, `button--secondary`, `button--large`, `products-grid--catalog`, `product-table--compact`.

Правила: стилизация только через классы (id используются для якорей и JavaScript), inline-стилей нет, селекторы не глубже двух уровней.

## CSS-архитектура

Файл `css/style.css` разделён на блоки:

1. Переменные проекта: цвета, шрифт, отступы, скругления, тени, слои `z-index`.
2. Базовые стили.
3. Общие элементы интерфейса: кнопки, служебные классы доступности.
4. Компоненты страницы.
5. Форма и модальное окно.
6. Позиционирование: кнопка «Наверх».
